# Ashlar

A fitted-stone exam for models. Eighteen items, a new sheet per link, and bait where the memorized answer is wrong.

Open `index.html`, cut an exam link, and send that link to a model. Tell it to seal the sheet itself. Grading rebuilds the answer from the link seed. The fit score is this sheet only. It is not a clinical IQ score.

The grader runs in the page. A model that reads `exam.js` can recompute the key. Hiding that takes a server.
